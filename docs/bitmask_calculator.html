ArduPlane Custom — Bitmask calculator

Reads the fork's apm.pdef.json and lets you tick bits to compute values for params like FLIGHT_OPTIONS, OSD_OPTIONS, RC_OPTIONS, etc. Inspired by notes.stavros.io/ardupilot/bitmask-calculator.

How to use this calculator (click to expand)

Two ways to use it:

1. Run it locally on your computer (recommended)

  1. Save this page to your computer: right-click the page background and pick "Save As…" / "Save Page As…", or use Ctrl+S (Cmd+S on macOS). Save as bitmask_calculator.html anywhere convenient.
  2. Double-click the saved file to open it in your browser. Everything works offline once loaded — the page is pure HTML/JS, no server, no analytics.
  3. On first load, the calculator fetches apm.pdef.json from this fork's GitHub raw URL. If you're offline, click "Upload file…" in the Source dropdown to point at a local JSON instead.

2. Use it directly via a CDN (no download)

GitHub's raw.githubusercontent.com serves HTML as plain text and won't render. Use a "raw to rendered" CDN like raw.githack.com: 

https://raw.githack.com/erwinquilloy/ardupilot/master_custom_4.6.3_light/docs/bitmask_calculator.html

Bookmark that URL and it always serves the latest version from the light branch.

Then, to compute a value:

  1. Wait for the parameter list to load (the Source bar will say "Loaded N bitmask params" in green).
  2. Pick the parameter you want to calculate (e.g. FLIGHT_OPTIONS) from the Parameter dropdown.
  3. Tick the bits you want enabled. The Value (decimal) field updates live with decimal, hex, and binary representations.
  4. Use Copy to put the value on your clipboard, then paste into Mission Planner / MAVProxy / QGroundControl as the parameter value.

To reverse-engineer an existing value:

  1. Pick the parameter from the dropdown.
  2. Type or paste the integer value into the Value (decimal) field.
  3. The bit checkboxes will reflect which bits are set.

Switching branches:

Use the Source dropdown to pick the light or full branch's apm.pdef.json. Content is byte-identical between the two on this fork — the strip is only of hardware backends at compile time, not of parameter definitions — so either works for the calculator.

Idle.

Built for the erwinquilloy/ardupilot fork of ArduPlane. Param metadata is auto-generated from the firmware source by Tools/autotest/param_metadata/param_parse.py; this calculator is a pure-static HTML/JS page (no server, no analytics) and runs entirely in your browser.
