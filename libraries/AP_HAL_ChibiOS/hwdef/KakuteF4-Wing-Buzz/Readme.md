# KakuteF4-Wing-Buzz (fork tone-buzzer variant)

A fork-only variant of `KakuteF4-Wing` that adds a hardware **ToneAlarm**
(pitched-tone) buzzer on the board's addressable-LED (**"LED"**) pad. The
stock Holybro Kakute F4 Wing defines *no* buzzer at all, so ArduPilot tunes
(arming, GPS lock, auto-takeoff/launch cues, failsafe) otherwise only beep
through the DShot ESCs. This variant gives the board a dedicated passive
buzzer instead.

## What changed vs stock KakuteF4-Wing

The **"LED" pad** - `PA1`, the board's default servo output 7 / WS2812
NeoPixel strip output - is remapped from `TIM5_CH2` to `TIM2_CH2` and marked
`ALARM`. That sets `HAL_PWM_ALARM`, so `AP_ToneAlarm` drives a passive buzzer
with the full pitched tunes. `defaults.parm` disables the stock NeoPixel
function on output 7.

- **TIM2 is unused elsewhere** (PWM outputs use TIM1/3/5/8, system timer is
  TIM9), so no motor PWM group is affected.
- **Cost:** the addressable **LED-strip** output on the "LED" pad. The
  onboard **PC5 status LED still works**, and **no M1-M6 motor/servo output
  is given up**.
- **Board ID is inherited** (`Holybro-KakuteF4-Wing`), so the `.apj` flashes
  over the stock Kakute bootloader as a normal firmware update.

## Wiring

Wire a **passive** buzzer to the **"LED" pad** (PA1):

```
LED pad (signal) --> transistor base (via ~1k) --> buzzer -- +5V
                                       GND ---------------- GND
```

Use a passive piezo/transistor buzzer, not an active (self-oscillating) one -
the tone is generated by the FC on TIM2, so an active buzzer would ignore the
pitch and just drone.

> Do **not** use the PB15 / PINIO2 pad for this - on the Kakute F4 Wing that
> net drives the board's switchable power output (VTX/"Vsw"), not a free
> signal pad.

## Status

**Bench-test first.** This variant assumes the target board's "LED" pad is
`PA1` and its pin map matches `KakuteF4-Wing`. If you are flashing a *Kakute
F4 Wing Mini* (a distinct, smaller Holybro product), confirm it reports board
ID `Holybro-KakuteF4-Wing` and that the "LED" pad is the one you wire to.
Not part of any release fleet yet.
